**This repository is only a testing mirror.** It exists so the package can be
checked on many platforms with [R-hub](https://github.com/r-hub/rhub) via GitHub
Actions. For that reason the [HiGHS](https://github.com/ERGO-Code/HiGHS) solver
sources are included directly under `inst/HiGHS/`.

The canonical source repository, documentation and issue tracker live on GitLab:

**https://gitlab.com/roigrp/solver/highs/**

## Installation

From [CRAN](https://CRAN.R-project.org/package=highs):

```r
install.packages("highs")
```
